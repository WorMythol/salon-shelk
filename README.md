# Студия красоты «Шёлк» — демо-сайт для портфолио

Вымышленный салон в Омске. Статичный сайт без сборки: `index.html`, `style.css`, `main.js`, фото в `img/`.

Приёмы взяты у известных салонов:
- фото на весь первый экран и промо-полоса со скидкой первого визита (Heyday);
- лукбук сезонных дизайнов с одной ценой без доплат за сложность и хэштег для гостей (Paintbox, Нью-Йорк);
- блок «почему мы» с цифрами доверия и клубная подписка с привилегиями (Heyday);
- цитата основательницы крупным шрифтом (Maison Seventy Seven);
- запись в пару касаний и нижняя панель «Позвонить / Записаться» на телефоне (мобильная запись как главный сценарий).

Онлайн-запись в 4 шага (услуга → мастер → дата и время → контакты): занятость генерируется, запись никуда не отправляется.
Палитры: `sage` (по умолчанию), `powder`, `champagne`; ссылка `…/?palette=powder`. Кнопку «Цвета» можно убрать, удалив блок `.pal`.
Фото: Unsplash, бесплатная лицензия, авторы в `img/CREDITS.txt`.
